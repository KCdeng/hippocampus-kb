# 切块：按标题层级切，不按固定 token 数切

`chunker.py` 把每个 Markdown 先按 `#` 到 `######` 分成节，记录**祖先标题链**（如
`射出/多段速度/一段速`），再在节内按空行把段落组装到预算里。纯 token 锚点的定长切块在工程笔记上
不可用：它会把一张表格从中间劈开，让前半段丢掉表头，检索时两个半块都排不上去。

## 参数

| 参数 | 值 | 作用 |
|---|---|---|
| `MAX_CHARS` | 800 | 单块字符上限，超出先按句号切，整句仍超长就按行切 |
| `MIN_CHARS` | 40 | 短于它的块并入邻块，避免碎片吃掉候选位 |
| `kind` | table / text | 块内以 `|` 开头的行达到 3 行即判为表格块 |
| `EXCLUDE_ANY` | node_modules、.git、__pycache__、venv 等 | 任何层级都跳过 |

## 表格必须带着表头走

一张长表会被切成多块，每块**重复表头行**，否则第 2 块之后的列名全部丢失。判定表头要求
"首行以 `|` 开头**且**第二行是分隔行"——只认前两行以 `|` 开头的旧写法，会把没有分隔行的
两行小表的第一条数据行当表头吞掉，那行数据此后不出现在任何块里。

## 行号由切块过程携带，不做事后回搜

块的 `line` 字段指向它在原文里的首行。早期实现是切完之后拿块首行文字回原文搜，
同一首行在节内重复出现时（表头、空节标题）会命中前一处的行号：竞品域实测只有 83% 的块
落在正确行上，溯源到错的行比溯源失败更糟。现在偏移在切分时逐段累计，行号换算成
「节起始行 + 节内换行数」，重切后行号准确率 100%。

## 换档守门员

`chunker.py` 写出前会比对**输出目录里那份 `baseline.json`** 记录的块数，不一致就拒绝覆写：
块序一变，同目录向量档的行号全体错位，服务会静默换到一份错位的索引上。
确要换代必须先过评测闸门，或用 `--out` 写到隔离目录并显式 `--force`。
守卫按"输出目录有没有 baseline.json"判定，所以主库与每个独立语料库都自动受保护，不需要各自加代码。
