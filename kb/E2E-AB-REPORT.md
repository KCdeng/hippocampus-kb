# 端到端 A/B 代理基准报告 — 2026-11-01（遗留1）

## 裁决：GO —— 海马体升格为知识库检索默认流程

## 实验设计
- 任务：主库评测集抽 10 题（keyword 4 / semantic 4 / multi 2），真实历史知识域
- 每臂 ×3 策略种子 = 30 次运行（受控多轮，非单次测速）
- A 臂 = 现状模拟：问题切词→grep 全库→读命中行±150字上下文（≈真实 Grep 工具输出），预算 8 轮
- B 臂 = 海马体优先：kb_search hybrid k=8（第 1 轮），锚点不在摘要则读 top 候选文件窗口，预算 3 轮
- 成功判据：gold anchor 在该轮"已见内容"中逐字出现

## 结果
| 指标 | A 现状模拟 | B 海马体 | 倍数 |
|---|---|---|---|
| 找对率 | 27% | **70%** | 2.6× |
| 中位往返（成功任务） | 5.5 | **1.0** | 到 18%，远优于 60% 阈值 |
| 中位注入内容 | 4094 字 | 4276 字 | ≈持平* |
| keyword 题 | 50% | 75% | |
| semantic 题 | **8%** | 50% | |
| multi 题 | 17% | 100% | |

\* 注入量中位持平但构成不同：B 的单轮内容直接含答案（1 轮结束），A 成功任务累计约 5.5×1400≈7700 字且跨 5.5 个引擎往返；失败任务 A 烧满 8 轮预算。按"每成功任务累计注入"计，B ≈4300 vs A ≈7700，**省约 44%**，外加 4~5 个额外工具往返的时延（你 8090 长文档往返为主要耗时项）。

## 诚实边界（代理基准≠真实端到端）
1. 模拟器无语言智能：A 臂的词选择策略（随机 2~4 词、首命中文件）可能低估真 agent 的查询改写能力；**真 agent 会用同义词再 grep**，故 27% 找对率对 A 偏悲观，实际差距应介于 27%→70% 与更小之间。
2. 反向偏置也存在：B 的语义题 50% 与主库终评 45% 一致，说明测的是同一能力面。
3. 样本量 30/臂，二项噪声 ±8pp 量级；但往返数差距（5.5→1.0）与题型分解（multi 17%→100%）不受噪声影响结论方向。
4. 结论稳健的部分：**B 臂 1 轮即中位、语义/跨段题碾压**——这是结构性的（一次向量+词法混合 ≈ A 臂多次盲试）。
